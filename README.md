# 사무실 임포스터

어몽어스 규칙을 그대로 따르는 사무실 테마 웹게임. 회사 동료 4~10명이 각자 브라우저로 방 코드를 쳐서 들어온다.

## 시작하기

| 하고 싶은 것 | 더블클릭 |
|---|---|
| 동료와 하기 (내 PC 에서 띄우기) | `게임 실행.bat` |
| 혼자 봇 5명과 시험 | `혼자 시험하기.bat` |
| 고친 것을 인터넷 주소에 올리기 | `깃허브업데이트.bat` |
| 사내망으로 하기 (렉 적음) | `사내 서버로 하기.bat` |

파이썬이 깔려 있어야 한다(로컬 서버용). 배포 주소가 생기면 그 주소만 동료에게 주면 된다.

## 사내망 모드 (렉이 적은 방식)

평소에는 Firebase(싱가포르 서버)를 거쳐 한 번 오가는 데 0.25~0.4초 걸린다. 같은 사무실이면 사내망으로 직접 붙어 0.05초 안쪽으로 줄일 수 있다.

1. 방장 PC 에서 `사내 서버로 하기.bat` 더블클릭 → 서버 창이 뜨고 주소(`http://100.x.x.x:8898/`)가 보인다.
2. 처음 한 번 윈도우 방화벽이 "액세스 허용"을 물으면 **허용**. 회사 보안 정책으로 막혀 있으면 동료가 못 들어온다 → 그땐 평소 주소로.
3. 동료들은 창에 보이는 주소로 접속. 방 만들기·코드 입력은 똑같다.
4. 서버 창을 닫으면 판이 끝난다. 방장 PC 는 켜 둘 것.

`lan_server.py` 는 게임 파일을 내주면서 `/db/` 에서 Firebase 의 REST·스트리밍을 흉내 낸다. 게임 코드는 포트 8898 로 열리면 그쪽에 붙는다(`js/cloud-config.js`).

## 조작

| 키 | 하는 일 |
|---|---|
| WASD / 방향키 | 이동 |
| E / 스페이스 | 사용 (임무, 긴급 회의, 환풍구, 두꺼비집). 서버 패널은 꾹 누르기 |
| Q | 킬 (임포스터) |
| R | 시체 신고 |
| Tab | 사보타주 메뉴 (임포스터) |
| Esc | 미니게임 닫기 |

## 규칙 요약

- 직원: 임무 5개씩. 전체 진행 바가 다 차거나 임포스터를 모두 추방하면 승리.
- 임포스터: 킬 쿨다운 25초. 산 임포스터 수가 산 직원 수 이상이 되거나, 서버 과열을 45초 안에 못 막으면 승리.
- 회의: 토론 60초 → 투표 30초. 동점이나 건너뛰기가 많으면 아무도 추방되지 않는다.
- 사보타주: 정전(창고 두꺼비집에서 복구), 서버 과열(서버실·렌더팜 패널을 두 사람이 동시에).
- 유령: 벽을 통과하고 남은 임무를 계속한다. 유령 채팅은 유령에게만 보인다.

## 주소 뒤에 붙이는 시험 옵션 (로컬 전용)

| 옵션 | 뜻 |
|---|---|
| `?local` | Firebase 대신 같은 브라우저 탭끼리 연결 |
| `&bots=N` | 방장 탭 안에 가짜 참가자 N명 (1~9) |
| `&min=N` | 최소 인원을 N명으로 |
| `&me=imp` | 방장을 임포스터로 고정 |

예: `http://localhost:8897/?local&bots=5&me=imp`

## 구조

방장 브라우저가 `js/rules.js` 로 판을 계산해 Firebase `crew/<방코드>/st` 에 0.1초마다 올린다. 참가자는 `in/<pid>` 에 입력만 쓴다. 역할은 ECDH+AES-GCM 봉투(`sec/<pid>`)로 본인만 연다.

| 파일 | 하는 일 |
|---|---|
| `js/map.js` | 사무실 맵 데이터 (방 9칸, 물건, 시작 자리) |
| `js/geom.js` | 충돌 이동, 시야 |
| `js/rules.js` | 게임 규칙 전부 (순수 함수, Node 로 시험) |
| `js/roles.js` | 역할·임무 뽑기, 봉투 암호화 |
| `js/snap.js` | 방송용 상태 (역할은 안 싣는다) |
| `js/net.js`, `js/room.js`, `js/interp.js` | 모코파크에서 가져온 접속 부품 |
| `js/localnet.js` | `?local` 일 때 탭끼리 연결 |
| `js/view.js`, `js/hud.js`, `js/meeting.js`, `js/lobby.js` | 화면 |
| `js/tasks/*.js` | 미니게임 6종 |
| `js/devbots.js` | 시험용 봇 (`?local&bots=N`) |
| `js/game.js` | 조립 |

## Firebase

- 퇴근의 계단·모코파크와 같은 프로젝트를 쓴다. **이 게임은 `crew/` 아래만 쓴다. `scores/`(사내 랭킹)와 `rooms/`(모코파크)는 절대 건드리지 않는다.**
- 콘솔에 올릴 규칙 완성본: `docs/firebase-rules-crew.json` (기존 `scores`, `rooms` 블록 그대로 + `crew` 추가).
- 개발자 도구로 볼 수 있는 것(사내 게임이라 감수): 방장은 모든 역할을 안다. 모두의 위치와 유령 채팅은 Firebase 에 그대로 있다.

## 시험

```
node --test
```
